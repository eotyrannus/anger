# Task Tracking App

A lightweight task tracking application with support for issues, kanban boards, and sprints.

## Features

- **Issues**: Create, update, and manage tasks with title, description, status, priority, and assignee
- **Boards**: Organize issues into kanban-style boards with customizable columns
- **Sprints**: Plan and track work in time-boxed sprints
- **Filtering**: Filter issues by status, priority, assignee, and more

## Tech Stack

- **Backend**: Node.js, Express, SQLite (via better-sqlite3)
- **Frontend**: Vanilla HTML/CSS/JavaScript
- **Testing**: Jest with supertest
